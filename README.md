# Iqra Birthday Website

All website files are kept together in the ZIP root (no nested project/assets folders).

## Run
Open `index.html` in a browser, or deploy the ZIP contents directly to your static hosting provider.

The 26 gallery images are named `photo-01.jpg` through `photo-26.jpg`. Optional music files can be placed beside the HTML files: `soft-instrumental.mp3`, `dreamy-piano.mp3`, and `birthday-celebration.mp3`.

Every inner page includes a bottom **Next preview** navigation button.
